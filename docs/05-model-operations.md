# 模型接入与运行后台

模型接入使用统一请求契约和独立供应商适配器。支持云端 API 和本地 Ollama，允许按职责使用不同模型。云端基准采用 deepseek-flash，正式验收需实际调用；本轮设计未调用付费生成，也未验证用户密钥。

## 已核实的接入条件

截至 2026 年 11 月 15 日，DeepSeek 官方文档列出 https://api.deepseek.com 基础地址和 deepseek-flash 模型标识。接入使用 Chat Completions 路径，模型发现通过 /models；能力、上下文长度和可用参数按发现结果与适配器规则处理，不永久写死模型别名背后的版本。[官方接入](https://api-docs.deepseek.com/)、[模型发现](https://api-docs.deepseek.com/api/list-models/)

DeepSeek 文档区分 thinking、reasoning_effort、JSON 输出和流式响应。JSON 格式有效不等于符合领域 schema，仍须本地校验；空白结果、截断、工具调用中断均作为独立错误处理。使用的参数及其来源随调用记录。[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)

Ollama 适配器使用 /api/tags 发现模型，/api/chat 生成文本。能力和实际模型需从可用服务读取，不凭文件名判断模型可以成功推理。[模型列表](https://docs.ollama.com/api/tags)、[对话接口](https://docs.ollama.com/api/chat)

## 供应商能力模型

初始正式适配范围：DeepSeek、Ollama、通用 Chat Completions 协议，以及一个非兼容原生协议适配器。原生协议优先选 Anthropic Messages，具体请求契约在实施前按其官方文档锁定；未验证的适配器在 UI 标记未验证，不与已通过的服务混淆。

能力记录包含文本、工具调用、JSON 格式、严格 schema、流式输出、嵌入、图像输入、思考配置、最大上下文、最大输出、用量字段与取消能力。能力证据带 discovered_at、source 和 probe_result。通用兼容端点不能默认具有全部能力。

连接测试分为健康检查、模型发现、短文本、结构化结果、工具调用、流式恢复和用量核对。部分模型只适合叙事，不能被路由到未经验证的结构化裁定角色。没有嵌入服务时允许结构化加全文检索，不伪造向量。

## 职责路由

| 职责 | 输入 | 结果与要求 |
| --- | --- | --- |
| 意图解释 | 当前输入、短上下文、模式 | 类型化片段，限制长度 |
| GM 回答 | 授权知识、问题 | 有依据的解释，无世界写权限 |
| NPC 决策 | 自己的知识、目标和可行动作 | 候选行动与证据引用 |
| 社会裁定 | 参与者可知信息及规则约束 | 有限事件提案，不访问全世界秘密 |
| 叙述 | 已提交且玩家可见的语义结果 | 不新增实质事实的文字 |
| 记忆摘要 | 本角色经历与事实引用 | 可回溯摘要，不删除原始事件 |
| 作者辅助 | 作者授权设定 | 草案、冲突建议与内容生成 |
| 嵌入 | 已授权检索数据 | 带模型版本的向量 |

测试时所有可用文本职责可先映射 deepseek-flash，但配置结构允许替换。路由选择和回退是显式配置，禁止自动把只允许本地处理的内容发送到云端。

## 速度与深度

速度档为 fast、balanced、patient。深度档为 standard、deep、exhaustive。中文显示为快速、均衡、耐心，以及标准、深入、充分。以下是初始可执行配置基线，需用质量测试校准，不能宣传为实测速率。

| 参数 | 标准 | 深入 | 充分 |
| --- | --- | --- | --- |
| 关键人物复杂决策候选数 | 2 | 4 | 6 |
| 每次相关记忆条数上限 | 12 | 24 | 40 |
| 候选因果关系扩展层数 | 1 | 2 | 3 |
| 重要语义结果复核次数 | 1 | 1 | 2 |
| 平稳宏观过程最大聚合跨度 | 30 日 | 14 日 | 7 日 |
| 反思触发 | 显著事件 | 显著事件与计划周期 | 同左并增加冲突审视 |

记忆条数是上限，不强行塞满；硬事实、活跃义务与当前相关伤势优先保留。聚合跨度只是上限，遇到寿命、交易、突破等边界均提前截止；通过模块误差验证的解析过程可在不丢失重要事件的条件下扩大步长，并记录原因。

| 速度档 | 调度策略 | 输出策略 |
| --- | --- | --- |
| 快速 | 在供应商与本地资源允许范围内并发独立请求，优先低延迟且质量合格模型 | 先显示阶段和已提交简明结果，最终叙述随后完成 |
| 均衡 | 有界并发与公平队列，保持交互和后台模拟平衡 | 正常进度和流式表现 |
| 耐心 | 减少资源竞争，允许高质量路由与较长单调用等待 | 等待完整校验后呈现较完整表达 |

快速加充分仍执行充分档要求，可能更贵且仍需等待；耐心加标准不会自动变成更深模拟。不可将快慢等同于温度参数。并发初值云端 4、本地每设备 1，实际由能力探测、限流与负载调整；只是安全调度起点，不是吞吐承诺。

用户本次测试配置的总费用和总任务时间上限为 null，表示不主动按预算终止。每次请求仍有输出长度与网络超时，防止协议挂死。建议初值为连接超时 10 秒、无数据超时 180 秒、单次请求期限 600 秒，均可配置；长模拟通过多个持久调用完成，不能把整个 600 年任务绑定一个请求超时。

重试最多 2 次，格式修复最多 1 次；耗尽后暂停并报告。用户可重新启动失败作业，但系统不无限自我重试。429 使用服务端重试提示和抖动退避，401 不重试，能力不匹配不盲目换参数轰炸服务。

## 上下文构造

先做权限和分支过滤，再按当前硬规则、角色状态、当前事件、活跃义务、相关记忆、近期对话分配预算。设定内容标记为数据，不允许角色卡文本覆盖工具权限。结构化提示与自由文风分区。

输入预算等于上下文容量减去预留输出和安全余量；超长时先压缩低优先级对话，不能截掉当前规则和授权边界。若必需内容已超限，换用已授权且支持的模型或明确暂停，不静默丢弃硬条件。

缓存键包括模型、任务、规则版本、角色可见范围、分支、状态依赖版本和提示版本。缓存回复不会重复收费记账或执行状态事件；缓存过期和状态变化需要失效。供应商缓存命中以其用量字段为准。

## 用量与费用

每个调用保存 request_id、parent_trace、world、branch、job、role、provider、requested_model、reported_model、配置版本、开始结束时间、排队时长、首 token 时间、校验时长、重试次数、结束原因与错误类别。

Token 分开记录输入、缓存输入、非缓存输入、输出、推理以及其他供应商项目；供应商输出若已包含推理 token，不再重复加总。用量缺失显示 unknown；本地估算与服务端报告分列。用户看到单次、回合、世界、角色职责、模型、日期的汇总，并能导出不含秘密的 CSV。

费用采用带生效时间、币种、来源的 PriceVersion，按供应商计价项计算。峰谷价、工具费与重试费用单独记录，失败请求也可能产生费用。原币保存，汇率转换为可选估算；账单核对时保留估算差异。调用超时且未收到用量时标记可能计费，不能记为确定零元。[DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)

Ollama 提供生成数量与耗时字段，可用于实际速度统计；本地 API 费用通常不按云端 Token 收费，但电费与硬件成本只有用户配置后才能估算，不能显示总成本为零。[Ollama 对话返回字段](https://docs.ollama.com/api/chat)

## 后台操作界面

连接页支持添加供应商、端点、凭据引用、模型发现、连接测试和可用能力；路由页按职责指定首选与回退；运行页展示活动作业、世界时间、进度、中断和租约；调用页可筛选延迟、Token、错误、模型和职责。

费用页显示用量曲线、价格来源和估算状态；诊断页提供最小脱敏包，默认不包含正文、秘密、NPC 隐藏设定和凭据。高级调试正文记录需主动开启，提供保留期限和清理功能；删除调试正文不删除世界事实。

用户可停止新模型派发、暂停某世界、取消某次作业或只重试叙述。界面说明实际取消边界，不能把客户端中止连接等同于供应商停止计费。

## 凭据和数据流

用户已提供凭据用于未来接入，本轮不落盘、不回显、不放入配置示例。实现使用 secret_ref 解析操作系统秘密存储或进程环境。浏览器拿不到真实密钥，备份与导出排除秘密。供应商配置变更不改变历史调用的价格和模型记录。

云端调用只发送所需授权内容；选择本地限定策略后禁止云端回退。媒体插件和诊断导出同样执行数据范围检查。后台可见每次调用发送数据的类别，不把隐藏模型推理当作必须展示的调试信息。

## 验证与未决项

开发前锁定适配器依赖与文档版本，实际测试 deepseek-flash 的文本、结构化输出、流式用量及失败行为；本地服务恢复后通过 /api/tags 确认实际模型，并测量可用上下文、吞吐与显存竞争。当前无需用户再提供产品偏好；若服务地址不同于已检查端口，再针对性询问。

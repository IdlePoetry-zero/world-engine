# 世界引擎产品需求

本产品让玩家以自然语言与 GM 沟通，在规则稳定、人物自主、历史连续的虚构世界中生活。用户可以创作不同背景、编辑关键人物，进入世界游玩，也可以观察和干预世界。产品以完整功能交付为目标；各阶段只有工程依赖顺序，不以试用版替代约定功能。

## 用户与模式

个人用户同时可能是作者和玩家，但两种身份的信息范围分开。默认玩家模式仅显示角色可知信息；作者模式可查看和编辑世界真相；观察模式查看模拟轨迹，可选择全知或某角色视角。进入全知视角要显示剧透标识，不把看到的真相自动写入角色记忆。

本地自动创建所有者身份。未来账号认证替换身份来源，不改变世界归属、成员、授权与角色控制结构。未来多人可以有玩家、旁观者、编辑者和世界主持者；本次提供这些权限对象与接口测试，不提供完整在线大厅。

## 世界创作

流程：选择模板或空白世界 → 描述概念 → 配置机制 → 编辑地理和组织 → 创建关键人物 → 校验 → 试运行独立分支 → 创建玩家与正式开局。

设定包包括历法、空间尺度、物种和寿命、社会制度、物资、能力体系、通信、规则、实体模板、初态和作者剧情。自然语言背景保存在知识层；会影响行动的规则必须有可执行定义。用户不必编程，可通过表单组合内置规则；全新机制由扩展模块实现，AI 生成规则提案需校验，不能直接执行生成代码。

规则分为硬约束、世界事实、人物信念与叙事偏好。发生冲突时硬约束优先；修改硬约束需要发布新设定版本，并展示对现有存档的影响。模板更新不偷偷改变已有世界。

附带三个完整示例：低魔封建社会、现代城市社会、长寿修仙世界。每个示例都覆盖六类玩法；现代背景可以通过非致命冲突和职业技能承载战斗成长，不能凭空增加超自然能力。科幻等新背景通过模块配置扩展。

## GM 沟通与行动

默认输入模式为自动，另有问 GM、角色说话、行动、作者指令快捷切换。自动识别结果以轻量标签显示；低置信度且涉及不可逆结果时先澄清。明确行动直接执行，不对每一步重复确认。

| 输入 | 分类 | 世界影响 |
| --- | --- | --- |
| 这个境界有哪些已知限制 | GM 查询 | 不推进时间，按当前视角解释 |
| 我之前答应过他什么 | 回顾 | 查询承诺和记忆，不推进时间 |
| 如果拒绝邀请会怎样 | 假设 | 给出可知范围内的可能性，不预言隐藏结果 |
| 我问守卫城里发生了什么 | 世界内对话 | 生成可听见的言论，推进合理时间 |
| 我思考一下刚才的证词 | 角色行动或查询歧义 | 根据模式区别回顾与耗时推理，不擅自消耗数小时 |
| 如果没有危险，我就闭关十年 | 条件长期行动 | 明确危险阈值、停止点与默认策略后执行 |
| 让这个人物改名 | 作者编辑 | 作者模式执行，否则引导切换，不产生角色内神迹 |

GM 查询不能为未来提供确定答案；对于未知秘密，应回答角色尚不知道，而不是编造。作者模式可以明确查询真相。假设推演如果需要真正运行模拟，创建隔离分支，显示推演性质，不污染正式世界。

一段话同时含提问与行动时拆成有序片段；先回答必要澄清，再执行已经明确的部分。玩家可以取消尚未执行的计划；已经发生的事件只能通过分支回退。不得替玩家表达爱情、宣誓或作出重大选择。

## NPC 编辑与自主性

NPC 配置包括身份、外貌、语言风格、示例对白、稳定价值观、性格倾向、能力、财物、社会身份、关系、记忆、知识边界、秘密、长期目标、近期任务、日程与成长条件。必填为名称、身份模板、出生或年龄依据、初始位置；其他字段支持草案生成并展示补全来源。

静态模板与运行实例分离。作者可锁定设定，但锁定某种态度会限制人物发展，界面明确标记。关键 NPC 默认没有剧情无敌或强制爱恋；可单独设置保护规则。已经死亡的人物仍可作为历史、遗产、关系与记忆的引用对象。

关系有方向，记录信任、亲近、尊重、恐惧、敌意、依赖和义务，不将其压缩为单一好感度。任何重要关系变化附带事件原因。重复送礼影响递减，人物可识别操控；关系修复需要与伤害类型有关的行动。

人物试演在副本里运行固定情境：利诱、威胁、家庭冲突、证据反驳、资源不足和长期失联。试演报告展示行为与设定是否一致，不把模型解释当成不可质疑的事实。

## 六类深入玩法

| 玩法 | 机制与操作 | 失败及后果 | 深度验收场景 |
| --- | --- | --- | --- |
| 人物关系 | 结识、共同经历、合作、冲突、承诺、信任修复、亲密关系与边界 | 拒绝、疏远、误会、背叛、关系中断 | NPC 因家庭利益拒绝高好感玩家，玩家可用实际行动修复 |
| 日常生活 | 家庭、住所、职业、技能学习、作息、健康、节庆和社交 | 失业、疲劳、疾病、错过约定、生活压力 | 连续经营一种生活方式，与社会事件产生联系而不强推主线 |
| 探索调查 | 地点图、可达性、危险、搜索、证物、证词、来源和矛盾核对 | 时间消耗、证据损坏、错误指控、目标警觉 | 至少两条调查路径，存在可被证据推翻的传闻，真相不随猜测重写 |
| 经营生存 | 采购、配方、工时、雇佣、库存、运输、供需、契约、债务、损耗 | 断供、违约、受灾、资不抵债、人员流失 | 供应链中断影响价格和政治，玩家可调整生产、谈判或停业 |
| 势力政治 | 组织职位、成员派系、合法性、资源、法规、外交、制裁、联盟、动员、继承 | 政令不执行、分裂、政变、失势、条约破裂 | 领导人死亡引发按制度处理的继承，参与各方具有独立目标 |
| 战斗成长 | 感知、位置、准备、先后手、行动代价、伤害、士气、逃跑、治疗、训练、瓶颈 | 受伤、俘虏、死亡、装备损坏、突破失败 | 可谈判或撤离，胜利不抹除伤势；闭关成长消耗真实时间资源 |

六类系统共享同一状态。不能在经营页拥有一批货，而剧情中又说这批货不存在。战斗结果影响家庭、组织与经济；调查证据影响人际信任；政治决定影响通行、税收与生产。

各背景提供具体配方、规则、能力、制度和场景，不以空白编辑框作为玩法完成。正式内容验收每类至少 3 条跨模块剧情链，其中包含成功、部分成功和失败后继续生活的路径。

## 大规模与长时间模拟

正式容量基准采用 24 个国家和 24 个非国家大型组织，32 名关键 NPC、240 名存续具名人物、至少 120 个地点，并推进 600 个设定历法年。人口群体另行聚合，历史人物持续保留。国家和组织分开计数，避免对用户所说超过 20 个国家和组织作最小化解释。

短行动、日程、季节经济、政治变迁和百年历史使用不同尺度；同一事件必须在一个权威调度链上结算。长寿人物、短寿种族、职位继承、组织灭亡、技术传播、战争、人口和迁移均进入规则。

闭关界面说明时间目标、资源计划、停止条件、允许自动处置的范围。世界快进显示已提交日期、进度、重要事件数和实际用量；可暂停、取消剩余计划、恢复。长时间行动不能用一段总结直接覆盖整个世界。

学习与闭关可以选择安全值阈值。可在角色行动中填写 0 至 100 的整数，或在聊天中明确写「安全值不高于 40 时暂停」。作业绑定该角色本人的安全值，阈值已满足时留在当前提交，后续触发时保留剩余计划。其他危险和中断仍按原有世界规则处理。

玩家可以一次交代一段时间内的例行活动，例如按已有岗位的排班工作一个月，或沿已同意的路线跨国旅行一年。GM 展示计划、结束条件、可自动处理的日常事项、需要询问的例外以及可能发生的费用和风险。例行活动按既有规则结算，不要求玩家逐班、逐日确认。到期、达成指定存钱目标或抵达目的地时，以已提交记录给出摘要。岗位中断、路线受阻、补给不足或出现需要玩家授权的选择时，暂停在事件发生的时间并保留剩余计划。攒钱和购买分别授权，准备购买某物不等于授权花钱。玩家说「照常上班」时，若本人任职和已有排班能唯一确定接下来的班次，GM 应直接沿用，并在回执中注明首班与重复规律。旧档没有排班或存在多项合理选择时，只询问缺失的排班或任职信息。

长行动的交互频率由活动、已授权规则和世界事件决定。跨国旅行可以连续数月自动前进；例行赶路和已授权的自理在后台结算，跨境政策改变、路线封锁或需要决定是否绕行的遭遇可以交回玩家。遭遇强度和出现机会由设定、路线和世界状态决定，平安时段可以直接进入下一段。封建远行、现代攒钱及其他长活动共享这套授权和暂停机制，各设定决定哪些事件值得打断。玩家仅向 GM 提问时，可以查进度与来龙去脉，世界时钟保持在当前提交。

需要玩家介入的事件也可以是机会。比如旅人在边境遇到一支有时限的护送邀请，接受会改变行程或承担新义务时，GM 应让玩家选择；继续原计划也是有效选择。与玩家当前计划无关的变化可以留待摘要；玩家已经授权的例行行为在后台处理。计划中的几个安稳月份可以连续推进，出现事件时按其实际发生时间结算。

## 页面规格与线框

| 页面 | 必备功能 | 空状态与错误 |
| --- | --- | --- |
| 世界库 | 新建、复制模板、导入、存档列表、继续、归档 | 首次提供三个示例；导入错误给出字段位置 |
| 创建向导 | 背景、机制、世界初态、NPC、玩家、校验与预演 | 生成失败保留已填信息；冲突可跳转修正 |
| 游戏 | GM/角色通道、自由输入、状态、笔记、背包、关系、地图 | 断线保留草稿；进行中命令可查，不重复发送 |
| 世界编辑 | 地点、国家、组织、规则、资源、时代与事件 | 修改预览影响，引用失效禁止发布 |
| 人物编辑 | 全档案、秘密权限、关系图、目标、日程、试演 | 未填可补全，但显示草案与校验提示 |
| 历史与分支 | 时间检索、因果追踪、人物生平、检查点、分支 | 历史归档仍可查询；摘要可展开依据 |
| 模型后台 | 连接、模型、职责路由、速度深度、调用记录、价格和错误 | 服务离线显示原因与最近成功时间 |
| 系统设置 | 存储、备份、日志、扩展、权限、诊断、更新 | 恢复前展示目标版本，不覆盖唯一备份 |

游戏页桌面线框：

```text
世界 / 分支 / 日期                玩家视角      模拟暂停或运行
地点与在场人物   |  GM 说明与世界叙述             | 角色状态
已知路线         |  角色对话                     | 背包与承诺
                 |  结果：耗时与可见变化          | 已知人物
                 |  [自动 ▾] 输入内容             | 笔记
                 |  [发送] [取消待执行]            | 调用概览
```

编辑器采用列表、详情、校验三栏；普通玩家页隐藏实体 ID、Token 与内部裁定细节，调用概览按需打开。手机或窄窗口改为抽屉布局，不要求在手机上同时显示全部侧栏。

输入支持键盘提交与换行设置、历史查找、字号和行距、浅深主题、文本复制。加载状态不能仅靠颜色；流式叙述尊重减少动画设置。重要信息不只存在于图片或声音中。

## 存档与内容生态

每次成功世界提交均可恢复，周期快照加事件日志形成存档。重新措辞只改变文本，不重新投骰或改变事实。重新尝试必须创建分支。玩家编辑旧输入时展示将从哪个检查点分叉。

导入世界包和基础角色卡，保留未支持的原始扩展数据并列出兼容报告，禁用脚本执行。图片元数据中的角色卡同样按不可信数据校验。导出区分作者完整包与玩家可见报告，防止秘密被默认导出。凭据不属于世界包或存档。

## 质量与发布要求

不存在负库存、重复支付、死人继续执行普通日程、未授权玩家读取秘密、查询自动快进或模型错误导致隐式成功。所有速度深度组合都执行相同硬约束。

产品提供安装启动说明、配置诊断、模型连接测试、升级迁移、完整备份和恢复操作。系统故障不要求用户手改数据库。验收数值、自动化测试和真实模型测试见开发验收计划。

所有实现必须映射 R01 至 R18。需求变更记录原因、影响模块、旧存档处理和测试变化，不通过默默删除范围解决难题。

# 费用模型的当前核对

2026-11-15 重新核对 [DeepSeek 官方价格页](https://api-docs.deepseek.com/quick_start/pricing/)。当前 Flash 已采用高峰/非高峰价，不能继续用单一固定价格推算所有请求。

| 单位：USD / 百万 token | 非高峰 | 高峰 |
| --- | ---: | ---: |
| 缓存命中输入 | 0.003 | 0.006 |
| 未命中输入 | 0.15 | 0.30 |
| 输出 | 0.60 | 1.20 |

官方定义高峰为周一至周五 UTC 01:00–04:00 和 06:00–10:00，中国公共假日除外；周末和其他时段为非高峰。实际价格可能调整。上述是核对时的公开定价快照，不是用户账户的实际账单。

实施要求：

- 价卡必须保留来源、获取/生效时间和供应商报告的实际模型；别名映射变化不能沿用未知模型价格。
- 调用记录保留缓存命中与未命中量，供应商缺失用量时不能把未知填成零。
- 分时价格需要明确计价时点与节假日依据；未知时显示区间或未确定，不伪装成精确金额。未经验证的假日推测不能用来自动降低预算预估。
- 重试与取消可能产生计费，缺少供应商反馈时显示待核实项，不能只计算最后成功请求。
- 本地推理的 API 费用与电费/硬件成本分开；没有资源计量时不能声称总运行成本为零。

运行时已接入官方地址与模型匹配的 Flash 非高峰价卡。快照复核窗口为 30 天，超期或工作日可能属于高峰的窗口继续显示未知。单次调用按本次尝试的 UTC 开始时间估算。正式节假日历、价格更新管理和跨尝试总费用仍待实现。

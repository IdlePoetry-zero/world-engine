# 幻想乡 360 世界日验收

幻想乡 1.6.0 从「山上的神社」介入点开始，玩家以不靠普通食物的妖怪身份提交一次长休息。正式作业推进到 360 世界日，角色在终点仍活跃。世界使用实际 DeepSeek 云端调用，终点从创世重放得到相同的状态哈希。

- 已提交 21,690 个事务，共 23,070 条账本事件。云端调用成功 943 次，裁定接受 226 条暗骰事件。
- 记录 5,801 次规则短交流、310 条 NPC 私下发言或回复，并有 46 名人物参与自治。逐条源引用确认了 92 条私下发言承接先前的暗骰议题。
- 短交流产生 1,084 次实际熟悉度变化，显式关系事件产生 172 次实际数值变化。逐次回执以变更前后数值核对。
- 推进耗时 221.0 分钟，创世重放耗时 22.8 分钟。用量合计 4,170,399 token，按记录中的价目估算为 0.7560 美元，另有 21 次调用缺少可估价记录。
- 事务提交路径累计耗时 100.1 分钟，包含规则验证、序列化、账本和检查点写入。各子阶段的计时会重叠，测量原始汇总见脱敏数据。

## 交叉核验

红魔馆从日常储备转向发展储备，守矢神社因实际资源不足暂缓。到第四季度，两方都让相关资源限制继续影响内部议题。文与慧音的后续回应也延续了前一季度的关系。规则仍允许人物缺席、暂缓或继续自己的事务。部分相近的地点观察和偏正式的组织对白在抽样中仍有出现。

三组六日对照均通过从创世重放。现代都市另通过 60 世界日的云端复用对照、创世重放和备份恢复。后端 2,786 项通过，1 项按平台条件跳过。前端 23 项组件测试通过，另完成构建、静态检查及 390 像素宽度实测。

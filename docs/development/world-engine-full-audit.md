- 用独立 SQLite 目录执行应用启动和迁移。未建立本机会话的世界列表请求返回 401。现代、低魔封建、长生修行均通过建档、玩家和作者视图、玩家历史、备份导出和重启后读档。模型设置与媒体扩展目录读取成功。此次启动检查未调用生成模型。 [运行证据](../../.runtime/full-audit-inventory-20261124-231848/startup-smoke.json)

- 后端全量收集并执行 2,636 项。2,634 项通过，1 项失败，1 项因本机有 Windows 凭据管理器而跳过。规则、内容、领域和代理组通过 1,263 项。四组 API 分别通过 277、259、198、263 项，失败在第一组。适配、凭据、应用、模型、模拟和存储组通过 374 项、跳过 1 项。Starlette 测试客户端产生弃用警告。
- 承诺可靠性用例在完整回归和单独重跑中均中断。GM 回答入口新增 `enrich_modern_opening_goal` 调用，原测试替身只带 `repository`，导致既有的隐私断言没有执行。这是可复现的测试契约回归。正式启动与世界视图使用完整服务对象，本结果不能据以判定正式游玩中的承诺数据泄露。修复时应先恢复原断言，并用正式入口保留一条非现代背景的可见性对照。 [调用锚点](../../backend/world_engine/application/conversation.py#L910) · [既有用例](../../tests/api/test_promise_reliability_dialogue.py#L211)

## 可玩性结论

先让玩家正确读懂眼前的世界，再扩大玩法规模。非标准历法下的会面时刻与容量受限时的点名案卷，会直接改变玩家对下一步的判断。随后试做一次能回访的三日场景，观察玩家是否能发现 NPC 已经做出的决定，是否会带着自己的理由改变行程，以及是否愿意主动回来。工作、调查、赴约和离开都应是可行的生活选择。迁移到幻想乡、低魔封建或修行背景时，用各自资源、权限与人情规则产生后果。 [规则与通用性证据](world-engine-full-audit-1.md) · [三日试玩提案](world-engine-playability-plan-3.md)

长期模拟沿用用户已批准的既有连续区间口径。本次审计没有重启 600 年作业、测算在线多人吞吐或调用收费模型。既有证据的结果和本轮重复验证分别注明。 [既有验收口径](acceptance-matrix.md)

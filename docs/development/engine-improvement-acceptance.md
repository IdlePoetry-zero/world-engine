# 万象引擎改造验收记录

本记录用于核对评估报告提出的引擎改造。本轮围绕同一世界时钟下的行动、因果与知情，以及世界包对规则的配置能力做了隔离验收。东方原作角色扩充继续搁置。

| 验收目标 | 当前证据 |
| --- | --- |
| 聊天与面板共用持续工作路径 | 两条 HTTP 入口生成等价计划并跑完一个月。两位角色各领 30 笔工资，核对班时、库存、角色寿终、到期排程和创世回放。 |
| 中途决定和恢复 | 玩家班中出现继任选择，原班按选择结果在新租约上继续。拒绝旧租约和无租约的班次进度写入。分支的额外快进不会变成申报工时。 |
| 普通动作推进 | 移动经过 NPC 限时行动，等待、休息和练习经过到期事件。休息与训练保留分段前后的累计时长和收益。固定时窗作业拒绝计入外部命令推进的时间。 |
| 玩家能读懂时长 | 试玩状态栏和工作回执用世界历日期和可读时长。精确世界秒仍用于事件顺序、日志和回放，也可从界面悬停读取。 |
| 长区间聚合 | 以 30 小时为一天的 360 日世界通过普通长行动入口快进一年。安静时间按月级窗口推进，NPC 寿终仍在世界历第 85 日 00:00:17 结算。 |
| 跨地因果与消息 | 电池移交、值守报告、延迟送达、签收构成可追溯链路。验证了到场条件、收件权限、分支回放和备份恢复。世界包只改变发报条件即可停止后半条链。 |
| 可组合的规则 | 普通 ZIP 导入的《远岬站》和「听风林」复用在地考核。远岬站 1.3.1 的测试变体只调整合格线，便可改变相同角色的判定结果。 |

## 规则职责与复现

世界包声明考核场地、技能、门槛、前置凭证，以及剧情节点的条件、延迟和收件范围。引擎负责时钟顺序、授权、岗位与工资的核验、资源双向分录和事件回放。通报沿用现有剧情后续与知识投影，收件人可以在既有 GM 查询中引用自己的知识记录。使用限制和具体用例见[模拟说明](simulation.md)。

本地自动化按规则组、SQLite 集成和快速检查运行。真实 DeepSeek Flash 用隔离存档验证假设输入与实际发起工作计划。模型判定、计费和时延的脱敏摘要单独记录。GitHub 工作流和本地命令见[运行说明](runtime.md)。

2026-11-23 用提交的探针复跑真实模型验收。假设请求保持时钟和队列，执行请求结算 30 班、375 银币，创世回放一致。四次 DeepSeek Flash 调用共报告 23,169 token，调用累计约 17.94 秒。复跑报告位于 `.runtime/real-work-probe-lgkd301z/evidence.json`。

本轮时序测试使用小型世界、一个月的重叠班次和一个安静日历年。数百年性能参考此前独立运行的存档审计。云端 Actions 的执行结果在分支发布后验证。

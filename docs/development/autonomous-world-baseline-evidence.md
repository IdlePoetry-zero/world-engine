# 六年自主世界模拟历史基线

历史作业从幻想乡 `mountain-shrine` 开局以长休息推进，输入由脚本构造的受控人物规划响应。正式 API、内建作业进程、规则、账本与重放均实际执行。上轮报告标注世界包为 1.5.0。原始回执记载了介入点、玩法模式和目标时长，包文件摘要及精确版本字段缺失。此记录可用于对照时钟、提交、存档及规则行为。真实模型的参与、表现及费用由本轮云端记录提供。[上轮验收记录](autonomous-world-followup.md)

## 时钟和重放

幻想乡的历法每世界日为 86,400 秒，每世界年为 360 日。历史作业最初提交十世界年，后来按验收范围调整，在六年后的首个检查点停止。另从已验证的分支前缀接续五小时，核对恰好六年的边界。

| 核对点 | 世界秒 | 已提交事件序号 | 重放范围 |
| --- | ---: | ---: | --- |
| 约第一年 | 31,952,700 | 18,661 | 从创世通过 |
| 约第二年 | 62,517,600 | 42,099 | 从创世通过 |
| 约第三年 | 93,459,600 | 68,419 | 检查点接续通过 |
| 约第四年 | 124,549,200 | 97,751 | 检查点接续通过 |
| 约第五年 | 155,995,200 | 131,255 | 检查点接续通过 |
| 越过六年 | 186,630,300 | 165,501 | 检查点链通过 |
| 六年整 | 186,624,000 | 核对回执保留哈希 | 从 186,606,000 的分叉前缀通过 |

六年整为 2,160 世界日。原作业越过六年后，世界时钟与作业的提交时钟一致，玩家角色在 164,375 个检查边界保持活跃。上表最后一行的独立回执记录了精确时钟和重放核对，下面的事件汇总取自越过六年的原作业。

## 复现入口

在仓库根目录构建幻想乡 1.5.0，提交受控响应的六年长休息并从创世重放。此复现命令直接申请六年跨度，原验收的十年申请及中途停止步骤见历史记录。

```powershell
.\.runtime\venv313\Scripts\python.exe -B scripts/build-gensokyo-reference.py --playable-world
.\.runtime\venv313\Scripts\python.exe -B scripts/verify-autonomous-world.py mountain-shrine rest 186624000 --fork --from-genesis
```

当前构建的全介入点导入及回放覆盖见[世界包回归测试](../../tests/api/test_gensokyo_world_pack.py)。

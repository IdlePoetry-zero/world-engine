# 万象可玩性评审（三）｜让玩家有一次值得回去的约定

## 判断与证据

下一个版本先让玩家在两个都舍不得放弃的安排之间做一次选择，再给他机会亲眼见到后果。以现代城已有的调度员会面、班次和报酬为底，做完一次约十分钟的往返。是否值得继续扩充职业、治理和创作工具，等这十分钟的试玩结果来决定。

## 首选可玩切片｜末班之前，我答应过谁

开局让调度员约玩家在下一班前碰面，同站有一份足以占掉会面窗口的短工。给玩家看到两个安排的公开时窗和自己的可支配时间。等人可以听到一段有来源的合同说法；做工可以拿到工资和收工凭据；自行离开仍可继续生活。已有会面及工作分别能结算；需要新做的部分是让两者在同一局里真的冲突、在返站时被当事人认出来，并允许错过后主动补约。首版只写一个人物、两个地标、一个冲突和一次回访。

| 玩家时刻 | 玩家可做什么 | 权威事实与验收 |
| --- | --- | --- |
| 进站，约一分钟 | 看公告、看候车人、自定目标 | 两个窗口均有公开出处；询问细节不耗时 |
| 决定去留，约两分钟 | 等候、上工或离站 | 预估结束时间注明假设；确认后才写入行动 |
| 兑现代价，约三分钟 | 听完对方、收工领钱或在别处办事 | 逐支核对到场、对话、工资；缺席者得不到现场原话 |
| 回到站台，约三分钟 | 问起上回、约下次，或告别 | 当事人仅能提及亲历或获知的事；补约由本人接受或拒绝 |
| 离场，约一分钟 | 保存一句下次想做什么 | 重开保留个人意图与已知后果；不会自动接任务 |

建议固定同种子做三支存档，再做慢模型、跨刷新和错过窗口回归。真人门槛先招五位未读说明者；至少四位能在确认前说出自己可能错过什么，三位能在稍后重开时指出一个由自己选择造成的变化。记录原话及中途离开的原因。样本用于找阻碍，不估计留存率。若只能在研究员提示下回访，先改场景和对白，再投入新增系统。

## 设计候选（每行依次为现象或目标、机制、验收或代价）

以下全部是建议，尚未验证收益。首轮只排 02、04、08、12、20、23、34、45，其余按下述阶段择取。

### 入场与定向

01. 开档时容易按世界名随便选｜每个介入点配一句当事人的眼前难题｜盲选后玩家能用自己的话说出被什么吸引。
02. 开场消息和时钟分离｜把两件相撞的安排写进一张当地公告，并接到实际时窗｜改变班表后文案随之变化。
03. 角色描述很自由却难落到选择｜允许玩家选一个私人牵挂，决定首页优先展示谁｜去掉牵挂不影响 NPC 的事实与权利。
04. 人物初见缺少记忆钩子｜用一件与眼前事务有关的小物件介绍此人，如调度员那张折角时刻表｜第二次会面时能凭细节认人。
05. 世界时间缺少生活尺度｜以“下班后赶得上哪一班”解释时间｜跨日或换站后重新计算。
06. 教程打断沙盒体验｜开局只在玩家第一次碰到实际阻碍时解释对应规则｜熟手直接行动不见教学弹窗。
07. 地名彼此难区分｜每个开局地标提供一条角色可见的辨认线索和一条已知通路｜用文字模式也能走回来。

### 有代价的行动

08. 两项安排分别可玩却缺少取舍｜把已接受的会面与准备提交的班次放在同一条时间刻度｜两者不重叠时不会出现冲突提示。
09. 等待容易变成跳时按钮｜让玩家选“等到熟人出现、窗口结束或自己指定时间三者最早”｜指定上限不会被越过。
10. 连做多步容易误耗时间｜允许为连续行程设置最晚折返时间｜中断留下已完成路段，返程仍要行动。
11. 不接邀约缺少表达｜给婉拒、解释和沉默各自的对话机会｜沉默不会被记录为口头拒绝。
12. 分支收益容易只剩数值｜让赴约者有一条可追问的亲历说法，上工者有一份能出示的工资凭据｜分别测试能否引用及对方能否相信。
13. 预算有钱就失去意义｜提供最多能垫付多少的个人约束，报价超额提醒｜玩家可明确修改约束，旧报价不受污染。
14. 同一冲突总有最优解｜安排两种无法换算的收益，如私人信任与公开认证｜两支均有后续愿望可推进。
15. 玩家调查时可能只是点亮清单｜允许写下自己的预测再去核查｜揭晓后可对照原文，错误猜测不会污染案卷事实。

### NPC、对白与 GM

16. 人物答话后戏就停了｜让 NPC 有一个玩家帮得上、也可拒绝的小请求｜人物离场后请求有合理截止。
17. 泛泛地问缺少谈资｜可选一段自己掌握的原话作为本次追问依据｜隐私材料只能由有权接触的角色引用。
18. 证词矛盾反而被模型抹平｜并排呈现两人说法，请玩家决定找谁核查｜一个证人改口仍保留旧说法与日期。
19. 社交极易成为刷好感｜重复问同一问题时允许人物提出边界或改约｜重复发问不能重复领关系收益。
20. 再见时人物像初见｜根据双方亲历的上次会面或缺席写一句有依据的开场｜调度员不能凭空知道玩家去哪里工作。
21. 玩家不容易挑选 GM 问法｜从当前困惑提供“我怎么知道的”“我还来得及吗”两个问题｜回答显示依据和不确定项。
22. 假设推演可能泄露未来｜允许比较两个计划的已知成本和公开窗口｜不会显示人物尚未表达的决定。
23. 错过事件后容易弃档｜给玩家提出补约的机会，新时间须获对方同意｜接受补约不会倒填原会面的出席。
24. 长对白淹没决定点｜把与当下选择有关的原句折出，保留展开全文｜折出内容必须能逐字定位。
25. 玩家不知道为什么自由输入被拒｜对地点、对象、期限中的首个问题给可编辑的改写建议｜采用建议仍需本人确认。

### 场景与节奏

26. 场景切换只换地名｜返回时优先描述上次离开后可见的一个变化｜没有变化就沿用日常描写。
27. 系统事件密度与阅读速度不匹配｜可把偶发小事攒到下次休息再读｜会过期的当场选择仍及时出现。
28. 世界只在大事故时有趣｜给冷清场景安排收摊、换班等可旁观的小仪式｜旁观者可随时走开。
29. 玩家被连续钩子追着跑｜高潮后放一个只有日常活动的落脚处｜在此休整仍按正常规则推进时间。
30. 路线选择常看距离｜让已知路线各展示一次可遇的人或能办的事｜没去过的路只显示传闻及出处。
31. 只见结果难见过程｜同一地点在开工、完工、次日三个时点呈现不同可见痕迹｜归档重放对应阶段正确。
32. 任务结束太突兀｜给角色留一次署名、告别或归还借物的尾声动作｜跳过不扣报酬。
33. 长行动中每一步都打断会疲惫｜玩家可指定只为某人或某类机会停靠｜强制规则中断仍显示原因。

### 界面、离场与复玩

34. 结算被后续消息冲走｜回到场景时用一句话对照“原先安排”和“实际发生”，可查原回执｜退款、未完成、迟到不会写成成功。
35. 手机多人物时难辨发言者｜让当前回应对象紧贴发送区，切对象时带上名字｜滚过场景卡后仍能核对收件人。
36. 私人事务分散在面板｜可把一个自选承诺置顶，并从承诺回到相应行动｜换分支不会携带另一支的承诺。
37. 历史记录丰富但重返意图很弱｜退场时可以写一句留给明天自己的话｜重开后一键找到地点或人物，笔记可删。
38. 分支多了容易记混｜在分支点保存玩家当时的理由，并排展示当时已知条件｜其他分支未来信息不进入游玩投影。
39. 复玩容易照抄上一次｜结局后提供一个当初确实开放却没有走的入口｜遗漏秘密不被揭露。
40. 玩久之后忘了谁认识谁｜允许通过已见人物查第一次介绍人的记录｜不能推断未公开的亲属或从属。
41. 检验文字可访问性｜为长回执提供按人物和动作跳读的键盘锚点｜用键盘走完整个回访并保住焦点。
42. 重试时用户疑心两次扣时｜对同一请求归并等待、恢复、完成三个阶段为一条时间线｜刷新前后仅出现一次最终代价。
43. 短局缺少可带走的成果｜允许选取三条亲历事件组成个人游记｜引用附日期、来源，导出前可删私密条目。

### 作者工具、验收与长期扩展

44. 作者容易从百科写起｜提供“谁约谁、谁会迟到、错过后怎样再见”的情境模板｜空白包能用少量字段走通一轮。
45. 竞争选择可能名存实亡｜为作者画出从开局到双方时窗的最早抵达和最早完工时间｜不可达分支给出具体阻挡边。
46. 角色可见性难预估｜作者以指定角色、地点和时刻预览一段场景投影｜同一传闻在当事人与陌生人视角不同。
47. 调参可能把正常窗口缩没｜按一组种子报告各出口可达比例｜将代价和回执变化一并列出，避免光看通过率。
48. 想知道玩家为何停下｜在自愿试玩中记录停顿位置，结束后问当时想做什么｜报告只保留经同意的原话与匿名步骤。
49. 扩背景时容易只换名词｜作者需为同一时间冲突指定各背景独有的一条证据规则｜换背景后验证可公开的材料确实不同。
50. 长期晋升只有数值增长｜让上岗、接任或退任改变一次日常场景中的真实权限｜离任后旧身份不再能批准同类请求。
51. 家庭和继承容易只是换角色｜设计一件遗留物及两位对其意义有不同回忆的人｜继任者须经实际接触才能获得新说法。
52. 大世界的后果难被感知｜将治理决定追到一个常去地点的一种服务，如夜班增开｜经费到期后变化可解释，私人讨论保持私密。

## 扩展顺序与背景检验

**第一阶段，验证取舍。** 只在现代站台落实八项首轮候选。第一版用确定性文案跑通碰撞、缺席及返站；再用真实模型检验人物能自然回答“你那天等了多久”。比较新增呈现与现有版本的无提示试玩，优先观察做决定之前玩家看懂了什么。

**第二阶段，检验移植。** 封建林道让旅人决定赶在约定前见桥吏，还是停在途经点核对许可。核对凭通行记录；错过会面可以下次再约，过期许可仍须按制度续。幻想乡用村口查日影与赶去见人制造冲突，现场观察与转述仍按已有红雾规则结算。两者都是拟议编排，不能把现代工资制度或强制吃饭搬过去。通过标准为相同的选择结构产生三种能解释的不同后果。

**第三阶段，让别人写出来。** 先给一位没有参与引擎开发的作者模板和时窗预览。观察他是否能独立制作一个两次相遇、一次错过的短篇。作者若需写专用程序才能证明两条路都成立，优先补预览和诊断，再开第二个模板。

**长期，将后果从几小时拉长到一代人。** 从 50–52 选一件玩家曾经关心的事，逐步验证第二天、离任后、继任后的可见影响。若玩家连上次为何错过会面都记不住，先改善回访、离场和重开，暂缓增加模拟规模。

### 重排后的投入建议

现代站台仍排第一，理由是它可以用一次十分钟试玩同时检验时间、经济、社交、角色知识和持久化。全项目抽查改变了第二阶段的顺序：先检验**十分钟以后还有没有好玩的一天**，再把同一开局移植到两个背景。优先做下列 53–55，作为三种独立候选；任选一条做第二个切片。若工作、关系和机构不能在同一段生活中形成取舍，继续打磨开局会高估整体游戏深度。

53. 第三天的班次容易像重复领取工资｜从一次真实班薪回执引出岗位变动或排班决定，让已经做过这份工作的人在调班与兑现私人承诺之间选择｜无该经历者看不到专属回话，没人接班时按真实岗位状态处理；不得凭一句对白扣钱。
54. 停战后战斗与日常脱节｜在普通地点再次遇见对手，允许谈及双方确实经历的停战，或在双方愿意时另约切磋｜拒绝、接受、从未收到停战提议的三支各自重开，人物记忆与可选行动应有区别。
55. 调查结案可能成为沙盒死端｜让公开指认影响某位已知人物下一次接待方式，提供出示新证据和更正机会｜把公开错误、私人未决、已公开更正三支带到同一地点，逐一核对人物知情来源、关系及可读的后续。
56. 角色成长常被压成一次数值判定｜让同一段闲暇可用于突破准备或赴一次传授之约，由导师的公开安排与实际材料决定可行性｜材料不足时仍有真正可选的学习路径；失败后的耗时、损伤、错过的约定分别可追溯。
57. 自主行动发生在玩家视野之外｜在玩家常去的市场选择一件由 NPC 实际完成交易引起的公开变化，让玩家自行决定是否追问｜没有交易回执就不出现变化，NPC 的未公开计划不会被提早提示。
58. 机构权力难形成扮演感｜给已上任者一场带着工资账与储备约束的公开听取意见时段，允许暂缓决定并承担延迟的真实后果｜以同一资金余额比较批准、延缓、离职三支，核对权限、余额和当事人后来实际能知道的决定。

第二阶段首选 53，能沿用第一阶段玩家熟识的角色和地点，控制学习成本。若盲测显示玩家最想追查某人的说法，改选 55；偏好处理冲突者可用 54 单独验证。第三阶段再测试跨世界迁移和作者自制，最后考虑 50–52 的跨代延伸。体验指标增加一项：隔日回来，不看研究员提示，能否主动找到一个自己愿意继续承担后果的行动。

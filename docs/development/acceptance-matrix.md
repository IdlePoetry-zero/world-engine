# 需求与当前验收证据

2026-11-21 用户确认现有长期存档的测试量足够。R11 以这些存档的真实已审计区间为准，历史段落中的 600 年目标是原长测方案。

2026-11-22 确认本轮两项实玩门槛均有足够的代表性证据。复杂指令复用真实自动模式的明确授权、只读和含糊对象正反例；跨玩法连续性复用三背景分支的状态、对白和回放。此两项验收收口。只有发现会改变结论的具体缺陷，才做定向复测。额外的机构资金调拨、债务处置与清算、政治交接与外交后果由原验收工作自行延伸，本轮从开发和验收清单移除。下文的历史记录与后续方向用于追溯。

本机交付已按确认范围验收。NPC 人物一致性采用原有试演抽查与问题复核，长期容量采用现有连续审计区间。下文保留具体样本范围和超长存档冷读测量边界。

## 跨系统实玩验收

每局从一个开放局面开始，给玩家若干可见矛盾和可选方向。自然语言保留具体目标与对象，行动顺序由试玩中得到的线索与反馈决定。随机请求 ID 只生成一次，不为成功选骰。失败和偏离原设想时保留结果，再跟进其后果。用同一已提交状态分支，检查差异在角色记忆、资源、名望、任职及世界时钟中能否延续。机械专项继续覆盖单条事务、权限和恢复，跨系统证据另行记录。

复用下列已记录的实玩分支，核对明确选择造成的后果，以及拒绝、误判或错过时机后能否继续。核对后续对白与 GM 问答时，分别记录代控人物、作者设置和真实模型自主结果。对局只读问答应保持时钟、序列和摘要。出勤、登记与发薪属于单项回归，长期容量按已有逐提交审计区间核对。

| --- | --- | --- |
| 修仙远行 | 一份有期限的欠约与一条失散旧址的传闻来到同一个下午。玩家可先还约、亲身追查，也可改走可见的其他路径 | 搜索有落空可能。实际发现才能用于追踪。人不在场时世界照样推进，承诺按时处理。行动后的探索记录、角色信任和资源能随分支继续使用 |

延伸实玩采用局势卡，只规定各方起点与必查边界，玩家可以另选目标或中途改主意。每个局势安排可独立变化的期限或人物目标，给世界时间继续推进，再让玩家回来观察。发生意外后从实际结果接玩，保留原分支，并记录意外是否真的改变了下一步的选项。

- **现代 · 两个周末。** 两名成年人各有生活安排、对关系的理解和隐私边界。玩家可同时维系两段关系，也可明确拒绝、逐个解释、在各方同意后安排见面，或把时间留给自己。跟进几次互动后验证独立回应、同意的范围、信任修复及确切的消息来源；未公开的承诺只有在当事人告知或有明确可追溯的传播事件后才进入第三人的视角。

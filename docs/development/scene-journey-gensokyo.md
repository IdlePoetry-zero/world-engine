# 游玩界面、旅程与幻想乡设定包

开发分支 `feature/scene-journey-gensokyo` 从本机发布提交 `42b3042` 分出。此文记录设计和证据，交付状态以分项记录为准。

## 场景与叙事

游玩页采用场景与叙事两栏，窄屏按场景、叙事和输入顺序流动。场景数据来自提交后的玩家可见投影。人物在场需满足当前地点和角色可见条件。场景动作统一进入原有输入草稿，提交仍由会话入口和规则判断。舞台扩展接收受控的本地资源引用，地点背景、人物立绘和发言聚焦可以独立配置。没有可用资源时直接展示文字场景。

旧游戏参考集中在背景与人物如何并置、在场动作如何紧贴叙事、地图与侧栏操作如何共用入口。用户截图用于分析视觉层级。旧素材及角色卡正文不会作为新工程的运行时资源导入。恢复资料中记载 32 张人物卡、14 张地点卡，并区分了源码分析与实际观察到的开局界面。

## 路线状态

既有有序路线的授权时窗和持久游标保持为权威记录。新增作业投影仅为提交账号的当前角色返回路线时间线，地名来自当下可见投影，每段预计抵达只对应该计划实际在途的旅程标识。已抵达从作业的持久抵达游标读取。旧作业或角色切换后仍可使用已有的段数摘要。有选择或暂停时继续走既有作业接口。

## 人物日程

保留已有工作班次、赴约、目标复审与背景自理。可移动的例行日程由作者显式启用。到本地日历边界时先检查原站位、途中状态、活动冲突、天气环境、路线通行和到达时窗，再选择原目的地或作者登记的替代地点。移动仍由正式旅行事件结算。计划和已提交事件一起界定可见性与回放；人物真实抵达后才进入新地点的在场名单。没有路线、当日行不通或无活动冲突要解决时，只按既有状态生活，避免给每位居民每天制造空事件。

## 幻想乡内容来源

以独立世界包承载规则、人物、地点、道路、档案和开场案卷。原创人物承接玩家的日常往来和调查。设定包的区域与传闻说明注明哪些取自原作公开资料、哪些借鉴了旧项目表现、哪些为本包创作。幻想乡与外界的隔离、人和妖怪的合作及冲突、异变调查和仪式化弾幕是原作的世界基调。[东方 Project 官方概述](https://touhou-project.news/touhou_project/)

《东方求闻史纪》的出版社书页用于确认一手设定书及署名，官方杂志用于追踪原作者和编辑资料。未查到正文的资料只列书目，不用商品页替代细节出处。世界包采用原创可玩的故事文字和 NPC。分发和第三方素材另循官方同人创作指引。[一迅社书目](https://data.ichijinsha.co.jp/detail/75801063) · [KADOKAWA 官方杂志](https://www.kadokawa.co.jp/product/322511000388/) · [同人创作指引](https://touhou-project.news/guideline/)

世界书的月影旧闻参考《永夜抄》的满月异变，山路信仰参考《风神录》公开的神社背景，地底风井的异闻参考《地灵殿》对旧地狱的介绍。观月抄图、回灯节、灯影试手、山脚分水纠纷和地底交班案均是本包创作。[永夜抄](https://touhou-project.news/titles/th08/) · [风神录](https://touhou-project.news/titles/th10/) · [地灵殿](https://touhou-project.news/titles/th11/)

## 已核对的开发阶段

- 隔离实例的 Chrome 以 1440 和 390 像素核对游玩页。场景的「观察周围」只填入 GM 草稿，已有输入保留，抽查没有发出聊天写入，窄屏没有页面横向溢出。`frontend/dist` 的原本机发布首页仍沿用此前发布资产。
- 既有旅程回归 25 项通过；路段投影新增断言覆盖原路段抵达、无未发生的预计时点和不返回内部路线或旅程编号。
- 两种天气从相同结构的独立 SQLite 世界启动正式快进。晴天到主要地点，风暴到登记替代地点。出发在第 90 秒，抵达在第 120 秒，创世回放一致。
- 幻想乡首个独立包已通过预览、导入、原包下载、两个支持结论的独立证据路径、排除错误嫌疑人、同地公开误指认的信任变化、市场成交及独立备份恢复。该阶段为真实规则与 SQLite 提交测试，模型主演奏及更广背景整合仍在后续实测范围。
- 隔离 Chrome 用网页的 ZIP 上传、预览和确认入口导入「回灯之约」，进入回灯棚。其作者档案打开现有 NPC 的「作息出行」，在本地草稿启用开关，未发出写入。新增日程相关 API 检查包含玩家侧不暴露该字段及离开现场后不再显示人物。模拟、旅程和世界包备份联合回归 29 项通过。
- 设定包 1.1 扩充为 17 处地点、13 名 NPC、21 条双向路径、5 个组织及两个案卷。网页导入后核对了开场和 17 处地点。SQLite 实测折羽祐岚在晴天去观月石台，暴雨去束页廊，两支均按时回书铺；地底案卷能以现场物证结案，也能排除错认的嫌疑人。渡铃坞出发的三段旅程在抵达地底风井后等待选择，选择继续后沿同一作业抵达赤泥交班廊。回放和独立备份恢复通过对应样本。

## 在开发实例试玩幻想乡

在仓库根目录运行 `.\.runtime\venv313\Scripts\python.exe scripts/build-gensokyo-pack.py`。启动开发实例后，从「世界库 → 导入世界包」选择生成的 ZIP，预览后确认创建。可在「调查日志」建立案卷，从人里相邻地点寻找证词和凭据。可用路线随当前角色已知地点与通行条件变化。
